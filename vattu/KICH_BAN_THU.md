# Kịch bản thử — App kiểm kê vật tư (trước buổi kiểm kê)

Chuẩn bị: 2 điện thoại đã đăng nhập, máy in A4, vài tem QR part mẫu.

| # | Thao tác | Kết quả mong đợi | ✓/✗ |
|---|---|---|---|
| 1 | Tab **Đợt** → Tạo "Kiểm kê dd/mm/yyyy" | Đầu trang hiện tên đợt; máy 2 thấy đợt mới | |
| 2 | Tab **Vị trí** → Kho 1 → thêm tủ A01, 4 tầng | Hiện 4 nút tầng; thêm trùng mã A01 bị chặn | |
| 3 | **In tem** tủ A01 → in, dán lên tủ | 4 tem có QR + "Kho 1 · Tủ A01 · TẦNG n" | |
| 4 | Tab **Quét** → Bật camera → quét tem Tầng 2 | Bíp, hiện "Kho 1 · Tủ A01 · Tầng 2" | |
| 5 | Quét 3 part: part 1 để số lượng 1, part 2 bấm **+** lên 5, part 3 gõ 12 → Lưu | Mỗi lần hiện bảng Số lượng; sau Lưu báo "+n"; "Tầng này: 18 cái" | |
| 5b | Khi bảng Số lượng đang mở, quét tem part khác | Không ghi; nhắc "bấm Lưu hoặc Huỷ trước" | |
| 6 | Quét lại part 2 (cùng tầng) | Bíp kép, khung vàng **ĐÃ CÓ ở vị trí này: 5 cái**; đổi thành 6 → Cập nhật → "Tầng này: 19 cái" | |
| 6b | Quét tem Tầng 3 → quét lại part 2 → số lượng 2 → Lưu | Ghi được; bảng có dòng "Mã này còn ở: … Tầng 2 (6)" | |
| 7 | Máy 2 đứng Tầng 2, quét part 2 | Máy 2 thấy khung vàng ĐÃ CÓ (máy 1 đã quét) | |
| 8 | Máy 2 quét part mới | Máy 1 thấy "cả đợt" tăng ngay | |
| 9 | Bấm **Hoàn tác** | Lượt vừa quét bị bỏ, số giảm đúng số lượng của lượt đó | |
| 9b | Tab **Danh sách** → Theo vị trí → **Sửa SL** một dòng | Đổi số lượng, tổng cập nhật | |
| 10 | Bật chế độ máy bay → quét 2 part → tắt chế độ máy bay | Đầu trang "Chờ gửi 2" → "Đã đồng bộ" | |
| 11 | Nhập mã bằng tay | +1 như quét | |
| 12 | Tab **Danh sách** → Theo mã / Theo vị trí, tìm mã | Đúng số lượng, đúng vị trí | |
| 13 | Tab **Đợt** → Xuất Excel | File 3 sheet: tổng hợp theo mã, theo vị trí, nhật ký | |
| 14 | Đóng đợt → thử quét | Báo chưa có đợt đang mở | |

Ghi lỗi (bước, ảnh màn hình, điện thoại gì) để sửa trước buổi kiểm kê.
